For developers

Every night, each database is dumped, stored in a restic repository on the Studio, and loaded into the Studio's MariaDB as a ready-to-query copy (mysql -h mac-studio.local -u root -p).

Restore an older copy (on the Studio): restic -r ~/softwares/workspace/db-backup/restic-repo snapshots --tag <db>, then restic … dump <snapshot-id> /mariadb/<db>.sql > <db>.sql.

Logs: ~/softwares/workspace/db-backup/logs/ · Run now: sudo launchctl kickstart system/com.sandeep.db-backup
